## What

1. **Skip-gate перед STEP 5 Apify GMaps**:
   - Read `clients.business_profile.client_type` early (single SELECT)
   - Якщо ∈ `{hurtownia, sklep_detal, sieci_handlowe}` → skip apify_gmaps call
   - Insert `contact_enrichment` row з `status='skipped'`, `cost_usd=0`, `raw_payload.skip_reason='b2b_bad_fit'`
   - Push `sources_completed: { source: 'Apify_GMaps', status: 'skipped', note: 'b2b_bad_fit: client_type=...' }`
   - Fall through до existing `else if (params.apify_api_token)` branch для non-B2B clients

2. **Cost guard post-call (для non-B2B path, де Apify все ще fires)**:
   - `COST_GUARD_USD = 0.10` threshold
   - After `enrichContactsApify()` returns — check `result.cost_usd > 0.10`
   - Якщо tripped:
     - `console.warn` з clientId + cost_usd + threshold
     - `contact_enrichment` row status='partial' з error_message='cost_guard_tripped: $X.XX > $0.10 — promotion skipped'
     - raw_payload extended з `cost_guard_tripped: true`
     - **SKIP** canonical fields propagation (no phone/email/website до `clients` table)
     - **SKIP** apifyBusinessName/Category persistence (brand cascade STEP 6.6 не triggered)
     - sources_completed note: `cost_guard_tripped: $X.XX (promotion skipped)`
   - Data залишається у contact_enrichment.raw_payload для audit
   - Phase B continues для remaining steps

## Why

- **Phase 1 spike test 22.05 (Panorama+ALEO)** показав wrong-tool fit Apify GMaps для B2B hurtownie (Continental Opony case, 23% success cohort UC_HURT_WARZYWA_OWOCE). FAIL closure recommended skip-logic як cleanup item.
- Future Panorama/ALEO wire (S-DATA.2.A continuation) — replacement path для B2B. Поки що deferred per Phase 1 fail closure.
- Cost guard: Phase 1 lesson — `PAY_PER_EVENT` actors можуть billable per-result (100 items × $0.004 = $0.40 vs $0.02 expected, 16x overrun). Post-call sentinel захищає від silent cost overruns коли Apify повертає більше results ніж очікувано.

## Behavior matrix

| Scenario | client_type | cost | Apify call? | DB writes | sources_completed status |
|---|---|---|---|---|---|
| B2B existing classification | hurtownia/sklep_detal/sieci_handlowe | $0 | NO | contact_enrichment skipped row | `skipped` |
| Non-B2B, normal cost | gastronomia/inne/null | <$0.10 | YES | full upsert + canonical | `success`/`partial` per result |
| Non-B2B, cost guard tripped | gastronomia/inne/null | >$0.10 | YES (already executed) | contact_enrichment з flag, **no canonical promotion** | `partial` з `cost_guard_tripped` note |
| Token missing | any | $0 | NO | none | `skipped` (existing behavior) |
| First-ever analysis (no business_profile yet) | null | varies | YES — full path | normal | per result |
