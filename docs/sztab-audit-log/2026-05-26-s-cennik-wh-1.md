## What

Додано 4-й cennik tier `wielki_hurt` поряд з existing 3-tier auto (`standard`).

**Semantics:**
- `standard` — existing behavior, 3 progi (mały / średni / duży) auto-iterate за wartością koszyka. Threshold-based.
- `wielki_hurt` — locked single tier, ціни `price_duzi_gracze` зафіксовані at offer-send time, no iteration regardless of cart total.

**Tier locked at offer-send:** Vadym обирає `standard` або `wielki_hurt` у `SendOfferButton` modal перед wysłaniem oferty. Selection writes до `orders.cennik_tier` column. Klient у public order form бачить визначений cennik (UI badge + locked ceny), nie ma możliwości switch.

**Attachment branched:**
- `standard` → `Ziomek_Fish_Cennik_B2B_2026.xlsx`
- `wielki_hurt` → `Ziomek_Fish_Cennik_Wielki_Hurt_2026.xlsx`

---

## Why

Vadym потрібний gating mechanism для top-tier клієнтів (sieci, dystrybutorzy >5000 zł/mies). Standardowy 3-tier cennik exposed `price_duzi_gracze` тільки powyżej 4000 zł netto progu — niewystarczające для negocjacji з bigger players. Wielki Hurt cennik daje single locked price column без minimum order, ale tylko zaufanym klientom (manual gate via send-offer button).

## How

### Files

1. **scripts/071_cennik_tier.sql** (migration)
   - `ALTER TABLE orders ADD COLUMN cennik_tier TEXT NOT NULL DEFAULT 'standard'`
   - Partial index `orders_cennik_tier_idx` `WHERE cennik_tier != 'standard'` (most orders залишаться standard)
   - Applied via Supabase Management API HTTP 201

2. **scripts/seed-wielki-hurt-prices.ts** (data)
   - Re-seeded `products.price_duzi_gracze` за PDF Wielki Hurt 2026
   - 16/16 SKU matched, 1 anomaly flagged: Lp 5 Świeża kapusta WH=26.97 > duży=25.88 (Vadym data, not auto-fixed)

3. **components/clients/send-offer-button.tsx**
   - Radio selector UI: Standardowy / Wielki Hurt (between cohort dropdown + message textarea)
   - State `cennikTier` posted у `/api/clients/[id]/send-offer` body
   - Attachment filename preview reflects selected tier

4. **app/api/clients/[id]/send-offer/route.ts**
   - Parse `body.cennik_tier` (default `'standard'`)
   - Write до `orders.cennik_tier` na INSERT new draft
   - Branch xlsx filename (B2B_2026 vs Wielki_Hurt_2026)
   - Pass `attachment_filename` у email template data

5. **lib/notifications/templates/offer-email.ts**
   - Optional `attachment_filename` w `OfferEmailData` type
   - Hardcoded `Ziomek_Fish_Cennik_B2B_2026.xlsx` → templated, defaults to standard

6. **app/api/orders/[token]/route.ts** (public GET)
   - SELECT `orders.cennik_tier`
   - SELECT `products.price_duzi_gracze`
   - Response exposes `order.cennik_tier` + `products[].prices.wielki_hurt`

7. **app/api/orders/[token]/submit/route.ts** (public POST)
   - `Tier = StandardTier | 'wielki_hurt'` extended
   - `TIER_PRICE` mapping додано `wielki_hurt → price_duzi_gracze`
   - Branch: якщо `order.cennik_tier === 'wielki_hurt'` → locked priceKey, no iteration; else existing `calcTier()` loop
   - `tier_at_submit` writes literal `'wielki_hurt'` (TEXT column, no enum constraint per pre-flight 1.2 check)

8. **components/zamowienie/order-form.tsx** (public 5-step wizard)
   - `Tier` extended, `Product.prices` adds `wielki_hurt`, `OrderInitial.order.cennik_tier` added
   - `computeTierAndTotal(cart, products, cennikTier)` — branches by cennikTier
   - Step 1 "Co warto wiedzieć" hint: 3 progi vs 1 zablokowany próg
   - Step 2 sticky banner: violet "Cennik Wielki Hurt (zablokowany)" замість tier upgrade progress bar
   - TierProgressBar + TierHint untouched, тепер typed as `StandardTier` (rendered only in standard branch)

9. **app/api/orders/admin/[id]/items/route.ts** (admin edit)
   - `Tier` includes `wielki_hurt` → `price_duzi_gracze`
   - Add-item endpoint computes unit_price correctly для WH orders

10. **components/operacje/order-detail.tsx + orders-list.tsx**
    - `Tier` types + `TIER_LABELS` extended з `'Wielki Hurt'` / `'WH'`
    - `AddItemModal.priceKey` branches до `price_duzi_gracze` для WH tier

11. **app/operacje/zamowienia/[id]/page.tsx**
    - `availableProducts` SELECT додано `price_duzi_gracze`

### Backward compat

- Existing orders before migration → `cennik_tier='standard'` default. Behavior unchanged.
- `tier_at_submit` legacy 3-value column залишається TEXT free-form; нові WH orders write `'wielki_hurt'` literal. Pre-flight check (Step 1.2) verified HTTP 204 UPDATE z 'wielki_hurt' на test row — no enum violation.
- `products.price_duzi_gracze` column existed pre-sprint (used in audit). Re-seeded за PDF.
